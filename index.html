📝 Discord テキスト装飾ガイド

初心者でも簡単！コピペですぐ使える

🎯 装飾プレビューツール

✨ 基本的な装飾

太字
**太字** クリックでコピー
太字 のように表示されます
斜体
*斜体* クリックでコピー
斜体 のように表示されます
下線
__下線__ クリックでコピー
下線 のように表示されます
取り消し線
~~取り消し~~ クリックでコピー
取り消し のように表示されます
太字＋斜体
***太字斜体*** クリックでコピー
太字斜体 のように表示されます
太字＋下線
__**太字下線**__ クリックでコピー
太字下線 のように表示されます

💻 コード表示

インラインコード
`コード` クリックでコピー
コード のように表示されます
複数行のコードブロック：
```
コード1行目
コード2行目
``` クリックでコピー
シンタックスハイライト付き（JavaScript）：
```js
const greeting = "Hello!";
console.log(greeting);
``` クリックでコピー
シンタックスハイライト付き（Python）：
```python
def hello():
    print("Hello!")
``` クリックでコピー

📌 引用と区切り

引用（1行）
> 引用文 クリックでコピー
左に縦線が表示されます
引用（複数行）
>>> 複数行の引用 クリックでコピー
以降すべてが引用になります

🎨 特殊な表示

ネタバレ
||ネタバレ|| クリックでコピー
クリックするまで隠されます
見出し1
# 大見出し クリックでコピー
一番大きな見出し
見出し2
## 中見出し クリックでコピー
中くらいの見出し
見出し3
### 小見出し クリックでコピー
小さな見出し
リスト
- 項目1
- 項目2 クリックでコピー
箇条書きリスト
番号付きリスト
1. 項目1
2. 項目2 クリックでコピー
番号付きリスト
💡 便利なTips
  • 記号を表示したい場合は、前に \ を付けます（例：\* で * が表示されます）
  • 複数の装飾を組み合わせることができます（例：***__太字斜体下線__***）
  • モバイルアプリでは一部の装飾が表示されない場合があります
  • コードブロックの言語指定は、js, python, css, html, java, c, cpp などが使えます
  • 見出しは行の先頭に # を付ける必要があります
